# BANPRESTO BP964-BP965

Uses the public [kuzecores Downloader database](https://github.com/kuzearcade/kuzecores), selecting only its BP964/BP965 MRA and core classifications. The hardware family is Banpresto; `NMKBP964` remains the upstream core identity. Core development: [kuzearcade/Arcade-NMKBP964_MiSTer](https://github.com/kuzearcade/Arcade-NMKBP964_MiSTer).

MRAs and recursive alternatives retain their names, contents, hashes, sizes, tags and effective download URLs. Navigation moves to `_Arcade/_Arcade Systems/_BANPRESTO BP964-BP965/`; the core remains in `_Arcade/cores/`.

The latest valid dated release is selected independently for each identity from the approved distribution records, never by scanning developer branches. The immutable RBF URL, MD5 and size remain authoritative. Unexpected identities or mutable RBF URLs stop publication. Future source MRAs/alternatives with these classifications enter automatically after normal validation. Other kuzecores families are not approved by this module.

Managed through the existing registry and included in Arcade Systems Complete. TATE uses the same scoped inventory and the frozen matrix; it does not include cores or non-matrix games.
