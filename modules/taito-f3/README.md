# TAITO F3

This subscription includes its required downloadable RBF records at `_Arcade/cores/`, using the original developer URLs, filenames and payloads. A separate upstream subscription is optional for these dependencies. Required ROMs, BIOS, keys and media remain user-supplied. See the [core dependency audit](../../docs/managed-core-dependencies.md).

Uses the [MeatCores database](https://raw.githubusercontent.com/meathax/meatcores/db/db.json.zip), selecting `arcadearcadetaitof3` only. MRAs install under `_Arcade/_Arcade Systems/_TAITO F3/`. Regional alternatives install beneath `_alternatives/`, keeping their original game-family hierarchy and upstream `_alternative/` download URLs.

This module includes the original `Arcade-TaitoF3` RBF record in `_Arcade/cores/`. The normal MeatCores subscription is optional for this system. Original payloads, metadata and source URLs stay unchanged.
