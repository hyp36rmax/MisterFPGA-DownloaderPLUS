# PGM (Ezio)

PGM MiSTer work by **Ezio Chiu**. Authoritative public distribution: [hyp36rmax/PGM-Mister-EZIOCHIU](https://github.com/hyp36rmax/PGM-Mister-EZIOCHIU), `_PGM/` on `main`.

The shared repository adapter places MRAs and recursive alternatives in `_Arcade/_PGM (EZIO)/`, retaining filenames and contents. Stable core families install in `_Arcade/cores/`. Only the declared distribution tree is used; legacy files and separate release archives are excluded. Verified payloads download directly from commit-pinned raw upstream URLs.

Artifact: `pgm-ezio.json.zip`. Permanent ID: `hyp36rmax/MisterFPGA-DownloaderPLUS/pgm-ezio`. Scheduled and manual updates use the existing independent publication workflow. Users supply their own ROM sets.

See [inspection and validation](../../docs/pgm-inspection.md) and the root README for the subscription.
