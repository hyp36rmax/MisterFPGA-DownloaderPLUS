# NAMCO SYSTEM 21

This subscription includes its required downloadable RBF records at `_Arcade/cores/`, using the original developer URLs, filenames and payloads. A separate upstream subscription is optional for these dependencies. Required ROMs, BIOS, keys and media remain user-supplied. See the [core dependency audit](../../docs/managed-core-dependencies.md).

Selects 7 primary MRAs and 3 alternatives from the [XelaNotPu database](https://raw.githubusercontent.com/XelaNotPu/XelaNotPu_MiSTer_DB/db/db.json.zip) at `_Arcade/_Arcade Systems/_NAMCO SYSTEM 21/`. Original filenames, recursive `_alternatives/` hierarchy, metadata and URLs are preserved.

```ini
[hyp36rmax/MisterFPGA-DownloaderPLUS/namco-system21]
db_url = https://raw.githubusercontent.com/hyp36rmax/MisterFPGA-DownloaderPLUS/main/dist/namco-system21/namco-system21.json.zip
```

Keep the normal upstream installation enabled for `Arcade-XNSYSTEM21_20261017.rbf` and `Arcade-XNWINRUN_20261017.rbf` under `_Arcade/cores/`. This module owns no executable cores and is included in Arcade Systems Complete. Choose Complete or the individual view for this folder.

The original inline supporter-credit pause images remain inside upstream MRAs, unchanged. No image, ROM, BIOS or firmware payload is extracted or repacked by DownloaderPLUS. The upstream MIT notice is retained in [UPSTREAM-LICENSE](UPSTREAM-LICENSE). See the [source and licensing review](../../docs/xelanotpu-namco-inspection.md).

Hardware approval does not grant STG collection authority: `collection_scope: excluded` preserves the existing closed collection source set.
