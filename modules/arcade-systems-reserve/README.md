# Arcade Systems Reserve

See [Arcade Systems](../../docs/arcade-systems.md) for installation, source and core requirements.

NAMCO SYSTEM 21, NAMCO SYSTEM 22 and NAMCO SUPER SYSTEM 22 are guidance-only Reserve folders for the XelaNotPu projects. Each `_READ ME.txt` retains the relevant developer reference and states that no approved automatic download source exists. These folders are included in Reserve and Complete; they install no cores, MRAs, ROMs or BIOS files.
