# SEGA MODEL 2

Public alphanu1 release, scoped to Model2. MRAs retain their source filenames and payloads; the required core installs under `_Arcade/cores/`.

The four standard MRAs stay in the system root. The four original `[15kHz CRT]` MRAs install under `_alternatives/`; their upstream URLs and contents are unchanged. Previously tracked root CRT files retire through normal Downloader cleanup, subject to deletion settings and other-store ownership. With deletion disabled they can remain for manual review. Untracked files are never deleted. See the [CRT migration review](../../docs/sega-model1-inspection.md).
