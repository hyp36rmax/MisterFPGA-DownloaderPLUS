# TAITO F2

The [official MiSTer Distribution](https://github.com/MiSTer-devel/Distribution_MiSTer) determines the current Taito F2 family through its `arcadetaitof2` classification. Credit belongs to the [Taito F2 MiSTer project](https://github.com/MiSTer-devel/Arcade-TaitoF2_MiSTer) and its developers and contributors.

Classified MRAs and their recursive alternatives install beneath `_Arcade/_Arcade Systems/TAITO F2/`. Payloads download directly from official sources; MRA contents, hashes, sizes, tags and effective URLs remain unchanged. Keep the normal official MiSTer installation enabled to manage the core in `_Arcade/cores/`. Users supply their own ROMs.

Artifact: `taito-f2.json.zip`. Permanent ID: `hyp36rmax/MisterFPGA-DownloaderPLUS/taito-f2`. Scheduled and manual updates follow current official classifications automatically. See [inspection](../../docs/taito-f2-inspection.md) and the root README for configuration.
