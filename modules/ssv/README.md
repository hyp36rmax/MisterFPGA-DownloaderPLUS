# SSV

Sammy / Seta / Visco SSV hardware, implemented by Meathax and distributed through the public [MeatCores database](https://github.com/meathax/meatcores). This module selects the SSV classification only; other MeatCores families retain their existing authority decisions.

All authoritative primary MRAs and recursive alternatives move from `_Arcade/_MeatCores/` into `_Arcade/_Arcade Systems/_SSV/`. Names, filename case, MRA contents, metadata, hashes, sizes and effective URLs remain unchanged. Cores remain under `_Arcade/cores/`.

Current dated releases are selected per approved core identity from the distribution records. Commit-pinned effective URLs, MD5 and size are preserved; unexpected identities or mutable core URLs stop publication. Future authoritative SSV MRAs and alternatives enter automatically after validation.

The managed module contributes to Arcade Systems Complete through the registry. Arcade STG (TATE) independently includes only qualifying frozen TATE rows; it does not inherit every SSV game or its core.
